Code Update Management (Deployment)

⚠️ WARNING: DANGEROUS OPERATION. This action executes a **Git pull** and **restarts** the `adminpanel` system service directly from the web application. A **brief outage** will occur during the restart. Proceed with caution.

Clicking the button will execute the **`deploy.sh`** script, performing the following steps:

  1. Git pull to fetch the latest code.
  2. Stop the `adminpanel` service.
  3. Delete and recreate the `venv`.
  4. Install dependencies and run migrations.
  5. Restart the service.

Deployment status will appear here.
