Add Quantum Machine

Creates a HEAppE cluster for a quantum machine of a QScheduler instance assigned to this HEAppE instance: cluster, queue, QPU queue group with accounting formula and optionally a project with QPU allocation. A machine can be shared by several HEAppE instances. When the assignment has notifications on (QScheduler page), the cluster gets its own QScheduler notifier and a new token, stored in HEAppE Vault.
