Admin token – 

                
            

            

                
HEAppE Management manages machines and notifiers of QScheduler 0.2.1+ only over its admin API,
                    through an admin proxy on 127.0.0.1, using the service's ADMIN_TOKEN. The token is stored encrypted.

                

                


                

                    
Current token

                    
To manage the same QScheduler from another HEAppE Management, enter this token there (Register existing → Admin token).

                    

                        
                        
                        
                    

                


                

                    
Set token

                    
E.g. the token shown by another HEAppE Management that manages this QScheduler. It is checked against the service when the admin proxy exists.

                    

                        
                        
                    

                


                

                    
Regenerate token

                    
Recreates the QScheduler container with a new ADMIN_TOKEN (short downtime).
                        Other HEAppE Management instances that manage this QScheduler lose admin access until they get the new token.

                    

                        
                        
                    

                    
                

                
This instance is reached over SSH into the container: set ADMIN_TOKEN in the service yourself and store it with Set token.
